# Ali Verney & Brendan Van Alstyne for Shakopee City Council

Campaign website for Ali Verney and Brendan Van Alstyne, candidates for
Shakopee City Council, November 3, 2026.

Static site, six languages (EN / ES / SO / VI / RU / FR).
Live at https://alivforshakopee.org

Stylesheet and script filenames are versioned (`css/style.v4.css`, `js/site.v2.js`)
because the filename is the cache key — assets are served with a four-hour
`max-age`. Bump the version on every change rather than editing in place.
